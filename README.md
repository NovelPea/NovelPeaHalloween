# NovelPea Halloween

A single-file, Halloween-themed writing studio for drafting novels, organizing story ideas, and browsing stories published in your local library. Works in mobile and desktop browsers.

## Features

- Create a demo account or log in
- Draft multiple novels and organize writing by chapter
- Automatically save work in your browser, with an option to turn autosave off
- Use the Story Bible, Characters, Places, and Notes sections
- Track word and character counts
- Format text with bold, italic, underline, strikethrough, headings, and lists
- Undo and redo editor changes
- Adjust editor font size and line spacing
- Edit your author profile
- Publish novels with descriptions, genres, and an optional cover
- Browse published novels and their table of contents in Discover
- Export a manuscript as a plain-text `.txt` file
- Switch between Halloween dark mode and light mode
- Navigate on mobile using the slide-out menu

## Getting started

1. Save the app code as `index.html`.
2. Open `index.html` in a modern mobile or desktop browser.
3. Create an account or log in.

No installation or server is required.

## Publishing and Discover

Published novels appear in Discover **only in the browser where they were published**. This demo does not use a shared server, so stories are not visible to other people or devices.

Publishing requires at least **3 chapters** and **2,500 words**.

## Saving and privacy

Account and writing data are stored in your browser using `localStorage`. Data stays in that browser on that device. Clearing browser storage may delete it.

**Do not use a real password or enter sensitive personal information.** This demo does not use a secure server.
